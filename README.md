# TCL Google TV Settings Simulator

A behavior twin of a TCL Google TV Settings menu, built from real photos of a reference TV. It is for L1 support agents on phone calls who have no TV in front of them. Settings hold state, dependencies grey out like the real TV, and Call Mode walks 17 troubleshooting flows step by step.

Build 2026.11.05.

Issue reports and usage counts go through the tool itself to Google Forms. Nothing typed into the tool is stored in this repo.
